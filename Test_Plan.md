# Manual Testing Test Plan

## 1. Project Overview
This project focuses on manual testing of a sample e-commerce application. The objective is to verify the functionality of login, user registration, product search, product details, shopping cart, checkout, and order history.

## 2. Testing Objectives
- Verify application functionality against expected results.
- Identify and document defects.
- Validate positive and negative scenarios.
- Check input validation and error messages.
- Ensure a consistent user experience.

## 3. Scope of Testing
The following modules are included:
- Login
- User Registration
- Product Search
- Product Details
- Shopping Cart
- Checkout
- Order History

## 4. Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Input Validation Testing
- UI Testing

## 5. Test Approach
Test cases will be executed manually using predefined preconditions, test steps, and expected results. Actual results will be compared with expected results, and any discrepancies will be documented as defects.

## 6. Test Environment
- Testing Type: Manual Testing
- Documentation: CSV files
- Version Control: GitHub
- Browser: Google Chrome
- Test Data: Sample user accounts and product information

## 7. Entry Criteria
- Test cases are documented.
- The test environment is accessible.
- Required test data is available.

## 8. Exit Criteria
- Planned test cases have been executed.
- Defects are documented.
- Test results are recorded.

## 9. Defect Reporting
Defects will be documented with a bug ID, title, preconditions, reproduction steps, expected result, actual result, severity, priority, and status.

## 10. Deliverables
- Manual_Test_Cases.csv
- Bug_Reports.csv
- Test_Plan.md

## 11. Project Status
Test cases and sample bug reports have been documented as part of this manual testing portfolio. Test execution results can be added as testing progresses.
