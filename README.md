# Manual Testing Portfolio

## About This Project
This repository contains my manual software testing practice work, including test cases, test scenarios, and sample bug reports.

## Testing Modules
- Login
- User Registration
- Product Search
- Product Details
- Shopping Cart
- Checkout

## Test Case Documentation
The `Manual_Test_Cases.csv` file contains 40 manual test cases covering positive testing, negative testing, input validation, and functional testing scenarios.

Each test case includes:
- Test Case ID
- Module
- Test Scenario
- Preconditions
- Test Steps
- Expected Result
- Priority
- Execution Status
